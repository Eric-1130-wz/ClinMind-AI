# ClinMind-AI 新界面运行说明

1. 双击本目录的 `start.cmd`，保持启动窗口开启。
2. 浏览器访问 **http://127.0.0.1:8000**，进入全新的接诊场景。
3. 点击桌上的电脑进入工作站，选择“问诊 / 体查 / 检验 / 处方 / 转归”，点击快捷操作或输入自定义指令。
4. 点击“报告”查看已取得的检查结果；点击“接诊记录”查看医患对话。
5. 点击“结案生成报告”，填写最终诊断，查看六维规则评分、反馈和操作时间线，可导出 JSON。

如果电脑已经安装 Python 3.10+，启动脚本会优先使用项目附带的 `.venv`；若环境缺失，会创建虚拟环境并安装 `requirements.txt` 中的依赖。安装依赖时需要联网，日常离线演示不需要 API Key。

## 页面与接口

| 用途 | 地址 |
| --- | --- |
| 新接诊场景 | http://127.0.0.1:8000/static/reception.html |
| 新电脑工作站 | http://127.0.0.1:8000/static/workstation.html |
| 原工作台 | http://127.0.0.1:8000/static/index.html |
| API 文档 | http://127.0.0.1:8000/docs |
| 服务状态 | http://127.0.0.1:8000/api/health |

源代码目录为 `ClinMind-AI_完整源代码包/ClinMind-AI_完整源代码包/aic_mech`。后端采用 FastAPI + SQLite + WebSocket，前端直接复用文件中两张 UI 设计对应的 HTML/SVG，不需要 Node 构建或单独启动前端。

## 数据与运行方式

- 当前提供 **1 个胸痛教学模拟病例**。“下一位患者”将重新开始这个病例。
- 两个新页面共享同一个浏览器中的会话标识，切换页面、刷新页面会恢复操作、报告和评分。
- 记录保存在源代码目录的 `runtime/clinmind.sqlite3`。每次操作和结案立即保存，监护状态每 10 秒保存；正常退出时再保存一次。意外退出最多丢失最近 10 秒的监护进度。
- 同一个服务进程只有一个模拟时钟。打开多张页面不会加快病情进展；关闭页面后，只要服务仍运行，未结案的训练仍会推进。服务停止期间暂停模拟，重启后继续。
- 默认仅监听本机 `127.0.0.1`，使用离线规则引擎。在线模型功能可在“AI 配置”中主动填写 Key 开启；在线模式会向配置的模型服务发送模拟对话。离线主流程已验证，真实在线服务的可用性取决于所填 Key、模型和网络。
- 当前是本地教学演示版本，未实现账号登录、多人权限或真实患者诊疗接入。

## 验证

在源代码目录执行：

```powershell
$env:PYTHONUTF8='1'
.\.venv\Scripts\python.exe tests/run_all_tests.py
```

测试覆盖引擎、REST 主流程、静态资源、SQLite 重启恢复、会话隔离、非法输入、禁忌状态回传、多监护页面计时与结案冻结。浏览器联调脚本在 `tests/browser_smoke.cjs`，需要 Playwright 与本机 Chrome；常规启动无需这些测试工具。

如 8000 端口被其他程序占用，可修改源代码目录 `.env` 中的 `PORT=8001` 后重启，并访问对应端口。
