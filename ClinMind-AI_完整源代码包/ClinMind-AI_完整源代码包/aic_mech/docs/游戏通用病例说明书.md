# 《急诊小诊室》游戏通用病例说明书

> 适用对象：大学生医疗实训课程 | 风格：2D 像素/卡通休闲实训
> ⚠️ **本说明书全部内容为虚拟教学病例，仅用于游戏实训，不构成任何真实医疗建议，不可用于真实临床。**

---

## 一、游戏医疗实训规则

### 1. 你是谁
你扮演一名**实习接诊医生**，在「急诊小诊室」接诊虚拟病人，目标是：**看对病 → 查对项 → 用对药**。

### 2. 每局流程（五步法）
| 步骤 | 你要做的事 | 游戏判定 |
|---|---|---|
| ① 观察病人 | 看动作/表情/面色提示，初步分轻重 | 观察越准，后续问诊越省时 |
| ② 问诊 | 点击问诊话题，收集主诉与病史 | 关键信息会点亮「线索图」 |
| ③ 辅助检查 | 选择需要的检查项目 | 冗余检查扣「临床效率」分 |
| ④ 确诊 | 从候选疾病中选出诊断 | **误诊有反馈教学，不惩罚好奇心** |
| ⑤ 治疗 | 按顺序执行治疗+护理 | 用错禁忌操作会触发「红线警告」 |

### 3. 计分规则（六维雷达）
- **确诊决策度**：诊断是否正确
- **鉴别思维**：是否排除了易错病
- **安全意识**：是否踩了禁忌红线
- **临床效率**：冗余检查越少分越高
- **医患沟通**：问诊是否耐心、安抚是否到位
- **急救处置力**：急症处理顺序是否正确

### 4. 三条铁律
1. **先问后查、先查后诊、先诊后治**——顺序乱了系统会提醒你。
2. **诊断不明前，慎用强效镇痛药**（会掩盖病情）。
3. **红线禁忌**（每份病历「禁忌事项」栏）绝对不能碰，碰了会直接教学复盘。

## 二、通用医学判断流程

```
问诊 ──→ 观察症状 ──→ 辅助检查 ──→ 确诊 ──→ 对症治疗
 │          │            │           │           │
 收集主诉   动作+体征     只查必要的   排除易错病   按流程+护理
 病史/诱因  生命体征      项目        锁定诊断     复查确认
```

**问诊口诀「P-Q-R-S-T」**（学生版）：
- **P**rovocation 诱因——什么原因引起/加重/缓解？
- **Q**uality 性质——疼是刺痛？胀痛？绞痛？
- **R**egion & Radiation 部位与放射——哪里疼？窜到哪里？
- **S**everity & time 程度与时间——多严重？持续多久？
- **T**ype 伴随症状——还有什么不舒服？

**生命体征速查（游戏内正常范围）**：
| 指标 | 正常范围 | 异常提示 |
|---|---|---|
| 心率 HR | 60–100 次/分 | ↑发热/疼痛/低血糖；↓重病信号 |
| 血压 BP | 90–139 / 60–89 mmHg | ↑↑危象；↓↓休克信号 |
| 血氧 SpO₂ | ≥95% | <93% 呼吸系统急症警示 |
| 呼吸 RR | 12–20 次/分 | ↑哮喘/发热；↑↑+讲话断句=中度以上发作 |
| 疼痛 VAS | 0–10 分 | ≥7 分优先处理 |

## 三、本游戏全部疾病速查卡

> 玩法提示：每张卡=「典型症状 / 鉴别要点 / 标准治疗 / 禁忌」。弹窗阅读版，先记要点再看病例。

### 卡1 病毒性感冒（急性上呼吸道感染）｜难度★
- **典型症状**：低热（37.3–38℃）、流清涕、打喷嚏、咽痒痛、乏力、轻肌肉酸痛
- **鉴别要点**：
  - vs 细菌性扁桃体炎：高热≥39℃ + 扁桃体白点/脓苔 → 需要抗生素
  - vs 流感：高热 + 全身酸痛剧烈 + 大范围流行季节
  - vs 肺炎早期：咳嗽咳痰加重 + 肺部湿啰音 + 胸片阴影
- **标准治疗**：休息 + 多饮水；体温>38.5℃ 或不适 → 对乙酰氨基酚；生理盐水漱口
- **禁忌**：❌ 病毒性感冒**不需要抗生素**；❌ 多种感冒药叠加（对乙酰氨基酚过量伤肝）

### 卡2 急性胃肠炎｜难度★
- **典型症状**：不洁饮食史 + 脐周阵发性绞痛 + 水样腹泻 + 恶心呕吐 + 低热
- **鉴别要点**：
  - vs 急性阑尾炎：**腹痛先于呕吐、压痛点固定在右下腹（麦氏点）+ 反跳痛** → 阑尾炎！
  - vs 食物中毒：多人同餐同时发病
- **标准治疗**：口服补液盐Ⅲ（防脱水是第一位）+ 清淡流食 + 蒙脱石散 + 益生菌
- **禁忌**：❌ 早期强力止泻（洛哌丁胺慎用，可能延长病程）；❌ 未评估就上抗生素；❌ 油腻饮食

### 卡3 支气管哮喘急性发作（中度）｜难度★★
- **典型症状**：**呼气性呼吸困难 + 哮鸣音（呼气相"哨笛音"）**、讲话成短句、SpO₂ 93–95%、夜间/诱因接触后加重
- **鉴别要点**：
  - vs 急性左心衰（心源性哮喘）：老年 + 心脏病史 + 粉红色泡沫痰 + 湿啰音
  - vs 气胸：突发一侧胸痛 + 该侧呼吸音消失
  - vs COPD：老年 + 长期吸烟史 + 慢性咳嗽史
- **标准治疗**：坐位 → **沙丁胺醇气雾剂吸入**（2喷，20分钟可重复）→ 吸氧（目标SpO₂≥95%）→ 短程激素（布地奈德/口服泼尼松）
- **禁忌**：❌ **β受体阻滞剂**（普萘洛尔等，诱发支气管痉挛）；❌ 阿司匹林（部分哮喘患者诱发发作）；❌ 镇静剂慎用（呼吸抑制）

### 卡4 低血糖症（药物性）｜难度★★
- **典型症状**：**心悸 + 冷汗 + 手抖 + 饥饿感**「低血糖四联」+ 头晕、烦躁、反应迟钝；糖尿病用药史 + 未进餐
- **鉴别要点**：
  - vs 脑卒中：**无偏瘫、无口角歪斜、无言语不清**（低血糖无局灶体征）
  - vs 癫痫：无抽搐、无意识丧失（本例）
  - vs 醉酒：无饮酒史；**关键：一针指尖血糖立刻见分晓（<3.9 mmol/L 即处理）**
- **标准治疗**：**「15-15规则」**：测血糖 → 15g 快糖（糖块/含糖饮料/葡萄糖片）→ 15分钟后复测 → 达标后补一份正餐
- **禁忌**：❌ **意识不清时喂食喂水**（误吸窒息）；❌ 不复测、不找原因反复发作

### 卡5 急性阑尾炎｜难度★★★
- **典型症状**：**转移性右下腹痛**（脐周→右下腹，麦氏点）+ 恶心 + 低热 + 厌食；**先腹痛、后发热**；行走时右下腹痛加重
- **鉴别要点**：
  - vs 急性胃肠炎：先吐泻后腹痛、压痛不固定 → 胃肠炎
  - vs 泌尿系结石：绞痛 + 向会阴放射 + 血尿
  - vs 胃穿孔：突发刀割样痛 + 腹部板状硬
- **标准治疗**：**禁食禁水 → 建立静脉通路补液 → 完善术前检查 → 腹腔镜阑尾切除术（+围术期预防性抗生素）**
- **禁忌**：❌ **泻药/灌肠**（诱发穿孔）；❌ 诊断未明前强效镇痛（掩盖体征）；❌ 右下腹热敷（炎症扩散）

### 卡6（高阶隐藏病例）Stanford A 型主动脉夹层｜难度★★★★
- **典型症状**：撕裂样胸背痛 + 双上肢血压差>20mmHg + 高血压病史
- **核心铁律**：❌ **绝对禁止抗血小板/抗凝/溶栓**；先β受体阻滞剂控心率，再降压；急诊 CTA 确诊 + 心胸外科会诊
- 详见内置病例《孙建国》

## 四、通用安全须知（所有病例适用）

1. 本游戏所有病人、病情、数值均为**虚构教学设定**。
2. 游戏内用药方案为**教学逻辑简化版**，真实用药请遵循医嘱与药品说明书。
3. 「红线警告」触发的操作在现实中可能造成严重后果——游戏让你安全地犯错、低成本地记住。
4. 遇到真实急症，请立即拨打 120 或前往正规医疗机构。
